Drum Kit Website

Overview

The Drum Kit Website is an interactive web application that allows users to play different drum sounds using either mouse clicks or keyboard inputs. The project simulates a virtual drum kit and demonstrates the use of JavaScript for event handling, audio playback, and DOM manipulation.

This project was developed as part of my web development learning journey to strengthen frontend development skills and create engaging user experiences.

---

Features

- Interactive drum kit interface
- Play drum sounds using mouse clicks
- Play drum sounds using keyboard keys
- Audio playback for different drum components
- Visual button animations and effects
- Responsive and user-friendly design

---

Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

How It Works

1. Users can click on drum buttons displayed on the page.
2. Users can also press designated keyboard keys.
3. JavaScript detects the input event.
4. The corresponding drum sound is played.
5. Visual animations provide feedback to the user.
